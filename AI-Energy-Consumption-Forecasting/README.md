# AI-Powered Energy Consumption Forecasting System

## Overview
This project forecasts future energy consumption using a Linear Regression machine learning model.

## Features
- Energy consumption dataset
- Linear Regression model
- Future energy prediction
- Model saved for future use

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib

## Project Structure
AI-Energy-Consumption-Forecasting/
- data/
- models/
- outputs/
- screenshots/
- src/
- main.py
- README.md
- requirements.txt

## How to Run
py -3.14 main.py

## Output
Predicts future energy consumption and stores the trained model.
