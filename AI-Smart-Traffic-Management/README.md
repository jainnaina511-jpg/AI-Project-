# AI-Based Smart Traffic Management System

## Overview
This project uses machine learning to recommend traffic signal actions based on traffic conditions.

## Features
- Traffic dataset
- Decision Tree Classifier
- Traffic signal prediction
- Saved trained model

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib

## Project Structure
AI-Smart-Traffic-Management/
- data/
- models/
- outputs/
- screenshots/
- src/
- main.py
- README.md
- requirements.txt

## How to Run
py -3.14 main.py

## Output
Recommends an appropriate traffic signal and saves the trained model.
