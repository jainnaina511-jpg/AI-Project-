# AI-Powered Predictive Maintenance for IoT Devices

## Overview
This project predicts possible equipment failures using machine learning based on IoT sensor data.

## Features
- Sample IoT dataset
- Decision Tree Classifier
- Failure prediction
- Saved trained model

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib

## Project Structure
AI-Predictive-Maintenance-IoT/
- data/
- models/
- outputs/
- screenshots/
- src/
- main.py
- README.md
- requirements.txt

## How to Run
py -3.14 main.py

## Output
Predicts whether a device is likely to fail and saves the trained model.
