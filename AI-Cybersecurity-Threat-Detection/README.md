# AI-Powered Cybersecurity Threat Detection System

## Overview
This project detects potential cybersecurity threats using a Decision Tree machine learning model.

## Features
- Login activity dataset
- Threat prediction
- Decision Tree Classifier
- Saved AI model

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib

## Project Structure
AI-Cybersecurity-Threat-Detection/
- data/
- models/
- outputs/
- screenshots/
- src/
- main.py
- README.md
- requirements.txt

## How to Run
py -3.14 main.py

## Output
Predicts whether a login attempt is a cyber threat and saves the trained model.
