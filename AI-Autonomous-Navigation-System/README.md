# AI-Based Autonomous Navigation System

## Overview
This project simulates an autonomous robot navigating towards a goal while avoiding obstacles using Python and Pygame.

## Features
- Robot movement simulation
- Obstacle detection
- Goal visualization
- Basic obstacle avoidance
- Interactive graphical interface

## Technologies Used
- Python
- Pygame Community Edition

## Project Structure
AI-Autonomous-Navigation-System/
- main.py
- assets/
- src/
- screenshots/
- README.md
- requirements.txt

## How to Run
1. Install dependencies.
2. Run:
   py -3.14 main.py

## Output
A graphical simulation displaying a robot navigating toward a goal while avoiding obstacles.
